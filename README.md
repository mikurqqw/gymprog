# IronCycle

Персональный планировщик силы, питания и восстановления. Исходные параметры и точная восьминедельная программа перенесены из предоставленного Excel. Приложение работает без сервера и учётной записи.

## Запуск

Нужен Node.js 24 LTS.

```sh
npm install
npm run dev
```

Открой адрес, напечатанный Vite, обычно http://127.0.0.1:5173/. Для установки на телефон и офлайн-режима используй production-сборку через HTTPS или localhost:

```sh
npm run build
npm run preview
```

Исходники находятся в текущей папке проекта. Готовая статическая сборка — в `dist/`. Относительные пути и HashRouter позволяют размещать её в подпапке статического хостинга. Публикация пока не выполнялась по последнему указанию пользователя.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run e2e
npm run audit
npx lhci autorun
```

Локально Playwright использует установленный Google Chrome. В CI используется Chromium: `npx playwright install --with-deps chromium`. Для Lighthouse на Windows задай `CHROME_PATH` равным пути к Chrome. CI описан в `.github/workflows/ci.yml`. Отчёты и скриншоты сохраняются в `artifacts/`, `test-results/` и `.lighthouseci/`.

## Структура

- `src/lib/`: чистые расчёты, программа, авторегуляция, питание, аналитика, прогноз, валидация, адаптеры хранения и тесты.
- `src/data/`: 119 исходных назначений Excel, восемь целей, 93 упражнения, 90 продуктов, статьи и научные источники.
- `src/components/`: общие элементы, таймер, журнал подхода, разминка, медиа и итоги недели.
- `src/pages/`: обзор, профиль, конструктор, программа, тренировка, самочувствие, питание, прогресс, тест 1ПМ, библиотека, справка, настройки.
- `src/i18n/`: русские и английские словари. Учебные материалы имеют поля `ru`/`en` рядом с данными.
- `public/`: manifest, service worker, иконки и локальная медиатека.
- `e2e/`: пользовательские сценарии, доступность, офлайн-работа и снимки адаптивной вёрстки.
- `docs/`: алгоритмы, проверка безопасности и соответствие требованиям.

Полное дерево исходников — `docs/FILE_TREE.md`.

## Реализовано

Точный цикл пауэрлифтинга сохраняет схемы и исключения Excel: три занятия, разгрузка на 4-й неделе, подводка на 7-й, активация и тест на 8-й. В эти недели меньше четырёх упражнений намеренно. Веса зависят от текущего 1ПМ и коэффициента формы, прежний рекорд не повышает рабочие веса.

Остальные цели генерируют 2–5 занятий: армрестлинг с медленной прогрессией, специализация рук с недельным объёмом, гипертрофия с соответствующим сплитом, общая сила, снижение жира, общая подготовка и свои приоритеты. Специальные движения имеют рабочие ориентиры на 8–12 повторов, прежние лучшие значения и коэффициент формы; это не оценка настоящего 1ПМ.

Журнал поддерживает факт по упражнению, отдельные отметки подходов, RPE, заметки, замены, видео, калькулятор блинов, разминку и таймер по абсолютному времени. При выключенном экране отсчёт не теряется; звуковое уведомление в фоне не гарантируется браузером.

Питание включает формулы Mifflin–St Jeor, ограничение дефицита, четыре макроориентира, типы дней, семь дней меню с подбором порций, замены, список покупок, аллергии и дневник. Значения пищевой ценности ориентировочные; крупы сухие, мясо готовое. Халяль-фильтр исключает свинину, сертификацию продуктов проверяет пользователь.

Прогноз даёт сценарии, учитывает стаж, относительную силу, возврат прежних рекордов, возраст, сон, питание, выполнение и журнал e1ПМ. Это прозрачная эвристика, а не научно подтверждённое обещание индивидуального результата.

## Данные и резервные копии

React Context и внешний адаптер состояния сохраняют JSON-схему версии 1 в localStorage. Чтение и импорт проходят Zod-валидацию, включая ссылки на упражнения. Миграция совместимой схемы версии 0 добавляет отсутствующие верхнеуровневые значения. Неизвестные версии отклоняются.

Экспортируй JSON в настройках. Импорт, сброс, загрузка демоданных и удаление еды требуют подтверждения и поддерживают отмену. Видео хранятся в IndexedDB на этом устройстве и не входят в JSON. Смена браузера/адреса, очистка данных сайта или удаление приложения могут удалить локальные данные — сохраняй копии.

## Как расширять

Упражнения добавляются в `src/data/exercises.json`: стабильный id, названия, мышцы, паттерн, оборудование, ограничения, замены, техника, ошибки, безопасность и медиаданные. Для нового движения добавь локализованные названия паттерна и мышц в словари.

Для новых целей редактируй `src/data/templates.ts` и генератор в `src/lib/program.ts`; расчёты покрывай поведенческими тестами. Основную программу меняй в `src/data/powerlifting.json`, сохраняя проценты вместо готовых килограммов.

Собственные `.webp`, `.gif` или `.mp4` можно положить в `public/media/exercises/<id>.<ext>` и перезапустить dev/build: медиареестр обновится автоматически. Явные `media.localPath`, `image`, `gif` или проверенный `youtubeId` имеют приоритет. При отсутствии медиа показывается схема с техникой; случайные внешние изображения не используются. Список нужных файлов — `MEDIA_TODO.md`.
